# Foodly!

Веб-приложение для домашней кухни: рецепты с расчётом КБЖУ, список покупок, меню на неделю на неделю и экспорт списка в PDF. Работает прямо в браузере, без сервера и регистрации. Интерфейс на русском, есть светлая и тёмная тема.

## Что умеет

- **Рецепты.** Фильтры и сортировка — в колонке слева (на телефоне — под кнопкой «Фильтры и сортировка»). Вид списка переключается справа над рецептами: крупные карточки, мелкие карточки или список; выбор запоминается. Палитра — оранжевый, фиолетовый и голубой; у каждого приёма пищи свой цвет: завтрак — оранжевый, обед — голубой, ужин — фиолетовый, перекус — янтарный. Создание, редактирование и удаление. У рецепта есть фото (файл ужимается до ~800 px или ссылка), порции, ингредиенты, шаги (их можно перетаскивать или двигать кнопками ↑/↓) и теги: приём пищи, кухня, свои теги. КБЖУ и клетчатка на порцию считаются автоматически, бейджи «Высокобелковое» и «Много клетчатки» ставятся сами. Есть поиск по названию и ингредиентам, фильтры (приём пищи, тег/кухня, особенности, диапазон калорий) и сортировка.
- **Черновики рецептов.** Недописанный рецепт можно сохранить кнопкой «Сохранить черновик» — без проверки полей; ингредиент, которого нет в справочнике, сохранится просто названием. Черновики показаны отдельным блоком «Черновики» над списком и не попадают в поиск, меню и колесо. Если свернуть вкладку или закрыть браузер с открытой формой, изменения тихо сохраняются в черновик. При закрытии формы с изменениями приложение спросит: сохранить черновик, не сохранять или продолжить. Для готового рецепта несохранённые изменения попадают в отдельный черновик и заменяют рецепт только после «Сохранить».
- **Диеты.** Встроенные диеты: вегетарианская, веганская, безглютеновая, безлактозная и кето. Диета исключает категории продуктов и отдельные продукты, у кето ещё лимит 15 г углеводов на порцию. Диеты можно выбрать в фильтре рецептов (подходят под все выбранные сразу) и в параметрах меню — тогда в меню на неделю и на колесо попадают только подходящие блюда. В карточке рецепта написано, каким диетам он подходит. Для диет добавлены 17 демо-рецептов.
- **Колесо фортуны.** «🎡 Что приготовить?» на экране рецептов: выберите приём пищи (или «Все») и крутите колесо. На секторах только эмодзи — название блюда появляется над колесом, когда стрелка на него указывает. Одно и то же блюдо не выпадает два раза подряд. На колесе до 12 блюд; если рецептов больше, «Перемешать» собирает другой набор. Выпавший рецепт можно сразу открыть или отправить в список покупок с нужным числом порций.
- **Фото по умолчанию.** У всех 24 демо-рецептов есть фото: 20 — с [Unsplash](https://unsplash.com) (бесплатная лицензия Unsplash), 4 (борщ, хумус, гречка, салат с фетой) — с [Wikimedia Commons](https://commons.wikimedia.org) (свободные лицензии). Под фото подписаны автор и источник, по ссылке — страница фото с лицензией. При первом запуске с интернетом приложение в фоне сохраняет копии фото на устройство, после чего они видны и офлайн. Если у демо-рецепта стояло прежнее фото по умолчанию, при обновлении оно само сменится на новое; свои фото пользователя не трогаются. Любое фото можно заменить своим или убрать в форме рецепта.
- **Справочник продуктов.** 177 продуктов с КБЖУ на 100 г (таблицы Скурихина / USDA) и весом единиц: 1 шт яйца = 55 г, 1 ст. л. масла = 17 г, плотность молока 1,03 г/мл и т. д. Если продукта нет, его можно создать прямо в форме рецепта.
- **Список покупок.** Позиции добавляются вручную, из рецепта (с нужным числом порций) или из плана питания. Одинаковые продукты суммируются даже в разных единицах (500 г + 1 кг = 1,5 кг), позиции «по вкусу» выводятся один раз. Список сгруппирован по категориям в порядке вашего маршрута по магазину. Купленное зачёркивается и уходит вниз, количество правится прямо в строке.
- **Меню на неделю.** Калькулятор дневной нормы по формуле Миффлина–Сан Жеора с учётом активности и цели; значения можно поправить вручную. Можно выбрать диеты, указать продукты, которые не используем, число приёмов пищи в день (3–5) и сколько человек будут есть. Генератор подбирает блюда на 7 дней с отклонением не больше ±10% по калориям. Каждый день — раскрывающаяся строка с фото блюд, калориями и отклонением от нормы; внутри — меню с фото, порциями и кнопками «Заменить блюдо» и «Подобрать блюда на этот день заново». Меню можно сохранить и одним нажатием добавить все продукты в список покупок (с учётом числа людей).
- **PDF.** Список покупок в формате A5 для телефона: крупный шрифт (14 pt), квадратики для отметки, категории не рвутся между страницами, внизу номера страниц. Файл называется `shopping-list-ГГГГ-ММ-ДД.pdf`.
- **Резервная копия.** Экспорт и импорт всех данных в JSON вместе с фото (заменить или объединить), сброс к демо-данным.
- **PWA.** Если открыть приложение через сервер, оно работает офлайн и устанавливается на телефон как приложение.

## Как запустить

**Самый простой способ:** откройте `index.html` двойным кликом. Всё работает, кроме офлайн-режима и установки на телефон. Для экспорта в PDF в первый раз нужен интернет: библиотека jsPDF грузится с CDN. Шрифт для PDF лежит в папке `fonts/`, поэтому кириллица работает и без сети.

**С офлайн-режимом:** запустите в папке приложения локальный сервер и откройте http://localhost:8000.

```bash
python3 -m http.server 8000
```

**На телефон:** выложите папку на любой статический хостинг с HTTPS, например GitHub Pages (Settings → Pages → Deploy from branch). Откройте ссылку на телефоне и выберите «Добавить на главный экран» / «Установить приложение».

## Как пользоваться

1. **Рецепты.** Нажмите «＋ Новый рецепт». Начните вводить продукт и выберите его из подсказок. Если продукта нет, выберите «＋ Новый продукт…» и заполните КБЖУ на 100 г. Если у продукта не указан вес выбранной единицы (например, «шт»), появится предупреждение с полем для веса. Итог КБЖУ на порцию виден внизу формы. Ctrl/⌘ + Enter сохраняет рецепт.
2. **В список покупок.** Откройте рецепт, выберите число порций кнопками −/+ и нажмите «В список покупок».
3. **Меню.** На вкладке «Меню» проверьте сводку (норма, приёмы пищи, на сколько человек); «Изменить параметры» раскрывает настройки. Нажмите «Составить меню на неделю». Нажмите на день, чтобы увидеть блюда; цветная метка показывает отклонение от нормы: зелёная — до 10%, жёлтая — до 20%, красная — больше.
4. **PDF.** На вкладке «Покупки» нажмите «Экспорт в PDF». По умолчанию в файл попадает только некупленное.
5. **Настройки.** Здесь тема, порядок и названия категорий, справочник продуктов (встроенные продукты можно редактировать, свои — ещё и удалять) и резервное копирование.

## Как хранятся данные

- **Рецепты, продукты, список покупок, меню, настройки** хранятся в `localStorage` (ключи `foodly:v1:*`), лимит ~5 МБ. Хранится один текущий план питания.
- **Фото** хранятся в IndexedDB (база `foodly`) как сжатые JPEG до 800 px. Лимит там гораздо больше: браузер обычно даёт сотни мегабайт и больше, точная цифра видна в «Настройки → Данные».
  - Загруженный файл сразу сохраняется на устройство.
  - Для фото по ссылке приложение пробует сохранить локальную копию. Это получится, только если сайт разрешает (заголовок CORS); тогда фото видно и без интернета. Если не разрешает, хранится только ссылка. При запуске через сервер сервис-воркер дополнительно кеширует такие картинки (до 150 шт).
  - Если IndexedDB недоступна (например, в некоторых приватных режимах), фото, как раньше, хранятся вместе с данными в `localStorage`.
- **Очистка:** при каждом запуске удаляются фото, на которые не ссылается ни один рецепт (например, после удаления рецепта). До перезагрузки фото удалённого рецепта остаётся, чтобы работала кнопка «Отменить». Фото, загруженные в форму, которую вы отменили или где заменили фото, удаляются сразу. Если данные прочитались с ошибкой, очистка не запускается.
- **Защита от автоочистки:** при работе через сервер приложение просит браузер не удалять его данные при нехватке места (`navigator.storage.persist`). Статус виден в настройках.

## Перенос данных на другое устройство

1. «Настройки» → «Экспорт данных (JSON)» — скачается файл `foodly-backup-ГГГГ-ММ-ДД.json`.
2. Перешлите файл на другое устройство (почта, мессенджер, облако).
3. Там откройте Foodly! и выберите «Настройки» → «Импорт данных…», затем «Заменить всё» или «Объединить».

## Ограничения

- Данные хранятся только в этом браузере на этом устройстве (`localStorage`). В другом браузере или в режиме инкогнито их не будет.
- Объём `localStorage` около 5 МБ (текстовые данные), фото лежат отдельно в IndexedDB. При переполнении приложение покажет предупреждение.
- Резервная копия с фото весит больше (около 30–150 КБ на фото).
- **Очистка данных сайта или истории браузера удаляет всё.** Регулярно делайте экспорт в JSON.
- Для первого экспорта в PDF и для перетаскивания шагов нужен интернет: jsPDF и SortableJS грузятся с CDN. Без сети шаги можно двигать кнопками ↑/↓. С установленным сервис-воркером библиотеки кешируются для офлайна.

## Структура

```
index.html            разметка и оболочка
style.css             стили, темы (CSS-переменные)
app.js                логика: Storage, Models, Nutrition, Recipes, Shopping,
                      Planner, PDF, Backup, UI/Router, Theme
manifest.webmanifest  манифест PWA
sw.js                 сервис-воркер (precache + stale-while-revalidate для CDN)
fonts/                Geist (WOFF для интерфейса, TTF-подмножество для PDF)
icons/                иконки 192/512 и maskable
docs/                 исходный бриф и промпт с техническим заданием
```

## Публикация на GitHub Pages

Settings → Pages → Build and deployment → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`. Через минуту приложение откроется по адресу `https://<логин>.github.io/foodly/` — с офлайн-режимом и установкой на телефон.
