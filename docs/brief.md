# Бриф: Приложение «Меню и Покупки»

## 🎯 Цель проекта

Создать одностраничное веб-приложение (SPA) на чистом HTML/CSS/JS (без сборщиков и фреймворков, либо с минимальными зависимостями через CDN), которое объединяет:

1. **Базу рецептов** с расчётом КБЖУ на порцию
2. **Список покупок** — агрегирующий ингредиенты из выбранных рецептов + произвольные позиции
3. **Помощник по планированию питания** — генерирует план на неделю и формирует закупочный список
4. **Экспорт списка покупок в PDF** — оптимизированный для мобильного просмотра (крупный шрифт, читаемая вёрстка)
5. **Тёмная/светлая тема** — переключаемая

---

## 🧩 Функциональные требования

### 1. Рецепты
- Создание / редактирование / удаление рецепта
- Поля: название, фото (опционально, base64 или URL), список ингредиентов (название, количество, единица измерения), шаги приготовления, число порций, теги (завтрак/обед/ужин/перекус, кухня, диета)
- Автоматический расчёт КБЖУ: у каждого ингредиента хранится БЖУ на 100 г; сумма делится на порции
- Фильтрация и поиск по названию, тегам, калорийности

### 2. Список покупок
- Два источника позиций:
  - вручную добавленные продукты
  - агрегированные ингредиенты из выбранных рецептов (с суммированием одинаковых позиций)
- Отметка «куплено»
- Группировка по категориям (овощи, мясо, молочное и т.д. — редактируемые)
- Кнопка «Очистить купленное»
- Ручная корректировка количества

### 3. Помощник по плану питания
- Пользователь вводит: цель (похудение / поддержание / набор), целевые ккал/БЖУ в день, ограничения (аллергии, нелюбимые продукты, тип питания)
- Помощник подбирает блюда из базы рецептов на 7 дней × 3–5 приёмов пищи
- Распределение КБЖУ по дням и приёмам — с отклонением не более ±10% от целевого
- Кнопки: «Перегенерировать день», «Заменить блюдо», «Сохранить план»
- Из сохранённого плана — кнопка «Собрать список покупок на неделю»
- Логика подбора — детерминированный алгоритм на JS (жадный/случайный с фильтрами), **без обращения к внешним API**

### 4. Экспорт в PDF
- Библиотека: `jsPDF` (CDN)
- Вёрстка PDF — **mobile-first**: крупный шрифт (≥14 pt), одна колонка, чёткие отступы
- Заголовок с датой, разделы по категориям, чекбоксы-квадратики для отметки карандашом
- Никаких мелких таблиц и горизонтальной прокрутки
- Имя файла: `shopping-list-YYYY-MM-DD.pdf`

### 5. Темы и UX
- Светлая тема: свежая палитра — мятный/лавандовый акцент, много воздуха
- Тёмная тема: мягкий графит (#1a1a1d / #232327), акценты сохраняются
- Переключатель в шапке, значение сохраняется в `localStorage`
- Учитывать `prefers-color-scheme` при первом запуске
- Адаптив: телефон / планшет / десктоп

## 🏗 Технические требования

- **Один HTML-файл** (или HTML + отдельные `style.css` и `app.js` — на твой выбор, предложи вариант)
- Хранение данных: `localStorage` (рецепты, список покупок, план, настройки)
- Никаких серверов и бэкенда
- Библиотеки только через CDN (`jsPDF`, при желании — `SortableJS` для drag&drop)
- Код структурирован: модули/классы/секции с комментариями
- Валидация форм, обработка пустых состояний (empty states) с подсказками
- Доступность: фокус, aria-атрибуты для модалок и переключателей

---

## 🎨 Дизайн

- Минимализм, скруглённые углы (12–16 px), мягкие тени
- Шрифт: system-ui или Inter (Google Fonts)
- Акцент: свежий мятный (#3ecf8e) + лавандовый (#a78bfa)
- Карточки рецептов с фото и бейджем КБЖУ
- Микроанимации: hover, появление модалок, переключение темы
